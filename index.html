Home Assistant Backup

A personal, non-commercial Google Cloud app that lets my own Home Assistant installation store backups in my own Google Drive.

What it does

This app is used only by the Home Assistant Google Drive integration on my private home server. After I sign in with my Google account, Home Assistant uploads its backup files to a folder in my Google Drive and can list, download and delete those same backup files.

Google data access

The app requests only the https://www.googleapis.com/auth/drive.file scope. That scope gives access only to files the app itself created or that I explicitly opened with it. It cannot see any other files in my Drive.

Who can use it

This app is not offered to the public. It is used only by me and members of my household for our own Home Assistant installation.
